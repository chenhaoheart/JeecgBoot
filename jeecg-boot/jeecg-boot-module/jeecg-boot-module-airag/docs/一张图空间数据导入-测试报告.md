## 1. 功能概述

此前页面仅支持 Excel 导入（无几何，不出图），带几何的空间图层只能靠 `sh_report_import/import_shmap.py` 离线脚本导入。本次新增后，在「一张图数据维护」页面选中空间数据集（小流域/断面/防治对象/隐患要素）→「导入数据」，可上传：

- **Shapefile 压缩包（.zip）**：内含同名 `.shp` 与 `.dbf`（`.shx/.prj` 可选）；
- **GeoJSON（.geojson/.json）**：FeatureCollection 或单个 Feature。

几何按表约束写入 `geom` 列（EPSG:4326，面/线经 `ST_Multi` 提升），导入即可在地图图层显示；调查年份与追加/覆盖语义同 Excel 导入。字段识别支持「白名单列名 / 中文列名 / 源字段名（如 WSWSCD、wswscd）」，wscd 清洗与类型归并口径与 `import_shmap.py` 一致。

## 4. 测试结果

### 4.1 单元测试（ShpParserTest，mvn test）

| # | 用例 | 预期 | 结果 |
|---|---|---|---|
| U1 | polygon 单环 + 双环（GBK 中文字段名/中文值/数值字段） | Polygon 3 顶点闭合；双环→MultiPolygon；「涉及水库」等中文字段名可取值；WSAREA=123.4567 | ✅ 通过 |
| U2 | polyline 单段/双段 | LineString(3 点)；MultiLineString(2 段) | ✅ 通过 |
| U3 | point | Point 坐标 [104.05,35.05]；NAME=跨沟桥梁 | ✅ 通过 |
| U4 | dbf 缺失时配对安全 | 几何照常解析、属性为空 | ✅ 通过 |

**测试中发现并修复的缺陷（2 个）：**

1. dbf 中文字段名按 ISO_8859_1 解码导致键名乱码（U1 首轮失败）→ 字段名改走与字段值相同的「UTF-8 严格 → GBK 回退」探测，修复后通过。
2. pyshp 将 Python `None` 写成字面量 `"None"` → 入库清洗增加 none/null/nan 归空（对齐脚本 `to_str`），固件同步修正。
