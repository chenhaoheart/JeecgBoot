防线一 · 生成前锁定

防治对象数、受威胁人口在生成前锁定为基准；第一章成文后自动提取面积、河长、比降、沟口高程作为基准——后续各章以此为锚。

防线二 · 每章自动体检

占位文字没写完、篇幅过短、表格残缺、应有表格缺失、百分比超 100%、内容与目标流域不符、第 5 章疑似编造历史灾害……逐章检查。

防线三 · 跨章数字核对

各章引用的关键数字与锁定基准比对（允许 2% 误差），防止「一章写 12.5 平方公里、另一章写 13.2」这类前后打架。

红色徽标

严重问题：内容不可用，需重修或编辑后重新审核。

黄色徽标

提示问题：供审核人参考，不阻断审核与导出，酌情处理。

原则：查不到的数据一律写「暂无调查数据」，宁可留白，绝不虚构
